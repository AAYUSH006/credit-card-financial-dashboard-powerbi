# Dashboard Design

# Overview

The Credit Card Financial Dashboard was designed to provide business stakeholders with an intuitive and interactive reporting experience. The dashboard focuses on delivering key financial insights, customer segmentation, and transaction analysis while maintaining a clean, consistent, and user-friendly layout.

The solution consists of **two report pages**:

1. Customer Report
2. Transaction Report

This separation keeps related analyses together, reduces visual clutter, and allows users to focus on specific business questions.

---

# Design Objectives

The dashboard was designed with the following objectives:

- Present business KPIs at a glance.
- Enable interactive exploration through slicers.
- Support executive-level decision making.
- Maintain a consistent visual theme.
- Minimize cognitive load by organizing related visuals together.
- Highlight key insights using simple and effective visualizations.

---

# Dashboard Layout

Each report follows a structured top-to-bottom layout.

```
KPI Cards
────────────────────────────────────

Global Filters / Slicers

────────────────────────────────────

Primary Business Visuals

────────────────────────────────────

Supporting Analysis Visuals
```

This layout allows users to understand overall business performance first before drilling into detailed analysis.

# Interactive Features

The dashboard includes several interactive components.

## Slicers

Users can filter reports by:

- Quarter
- Week
- Gender
- Card Category
- Salary Group

These slicers dynamically update all visuals on the report page.

---

## Cross Filtering

All charts support cross-filtering.

Selecting a value in one visual automatically updates related visuals, allowing users to perform interactive exploratory analysis without navigating away from the dashboard.

---

## Consistent Visual Theme

The dashboard follows a consistent design language:

- Consistent color palette
- Uniform fonts
- Standardized spacing
- Rounded KPI cards
- Clear chart titles
- Minimal visual clutter

This improves readability and user experience.

---

# Design Principles

The dashboard was developed following standard Business Intelligence design principles.

- Simplicity over complexity.
- High information density without overcrowding.
- Consistent formatting across pages.
- Interactive filtering.
- Meaningful use of colors.
- Logical grouping of related visuals.
- Clear hierarchy of information.

---

# Business Value

The dashboard enables stakeholders to:

- Monitor financial performance.
- Understand customer behavior.
- Analyze transaction trends.
- Identify profitable customer segments.

# Summary

The dashboard combines effective data visualization, interactive filtering, and business-focused design principles to provide a comprehensive view of customer and transaction performance. Its two-page structure allows stakeholders to quickly access high-level KPIs while also exploring detailed analytical insights through interactive visuals.
